HICP presentation — local run

1) Put your existing threshold_app_data.csv in this folder, beside app.py.
   (The app still opens without it, but Scene 12 uses a coarse preview grid.)

2) From Terminal, cd into this folder and run:
   python -m streamlit run app.py

3) Open the local URL Streamlit prints (usually http://localhost:8501).

4) Use the bottom ← / → buttons.
   On Scenes 7–11, the → button first advances the planned reveal states, then moves to the next scene.

5) For presentation, use browser fullscreen.

Design rule implemented:
- Scene 1: clean cold open; Lara/bootcamp credit fades in.
- Scenes 2–6: cinematic image + only progress dots/page number.
- Scenes 7–12: analytical frame + HICP footer + progress.
- Scene 13: clean ending, no progress shell.
